# Fotostock Workshop

Personal desktop tools for stock photographers (Windows and Mac): **Vārdotājs** (titles, descriptions and keywords for photos) and **Analītiķis** (sales from photo agencies). This repository contains the program releases and installers.

- Vārdotājs installers: [vardotajs/installers](vardotajs/installers)
- Analītiķis installers: [analitikis/installers](analitikis/installers)
- Privacy policy: [PRIVACY.md](PRIVACY.md)
