# Fotostock Workshop

Personal desktop tools for stock photographers (Windows and Mac): **Vārdotājs** (titles, descriptions and keywords for photos), **Analītiķis** (sales from photo agencies) and **Tirgotājs** (tracking submissions to agencies). This repository contains the program releases and installers.

- Vārdotājs installers: [vardotajs/installers](vardotajs/installers)
- Analītiķis installers: [analitikis/installers](analitikis/installers)
- Tirgotājs installers: [tirgotajs/installers](tirgotajs/installers)
- Privacy policy: [PRIVACY.md](PRIVACY.md)
